# Subexponential Weighted Counting and Exact Optimisation (MDPI version)

Deep Bhattacharjee. Single-column version of the paper, prepared for MDPI Preprints.

- `ETH_MDPI.pdf`: the paper (47 pages).
- `TexmdpiETH.zip`: the LaTeX source (`main.tex`) with its four PNG figures; it compiles with `pdflatex main.tex`.
- `main.tex`, `fig_*.png`: the same source, unpacked.

An earlier version is the Hexagon preprint [2610.00594v1](https://hexagonmath.org/2610.00594v1). The verification program and the release archive are in [creelie/eCon](https://github.com/creelie/eCon), Zenodo [doi:10.5281/zenodo.23718560](https://doi.org/10.5281/zenodo.23718560).
